# enterprise-agent-suite

企业级多智能体应用平台，采用单一 Git 仓库管理统一前端、三个独立 Agent API、运维协调模块及项目计划。

## 目录

- `agent-suite-web/`：统一 Web 前端。
- `agents/legal-consulting-agent/`：法律咨询 Agent。
- `agents/recruitment-assistant-agent/`：智能招聘 Agent。
- `agents/data-query-agent/`：智能问数 Agent。
- `agent-suite-ops/`：架构、部署与运维协调。
- `docs/plans/`：总体计划、模块计划和阶段记录。

`AI编程_智能问数实训(课件)/` 是本地参考资料，不进入 Git 仓库。
