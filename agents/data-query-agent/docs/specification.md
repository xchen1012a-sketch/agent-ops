# 智能问数 Agent 规格（真源）

## 1. 课件原文依据

来源：`AI编程_智能问数实训(课件)/06_智能问数/06_端到端案例实现.md`

课件学习目标原文：

> 独立搭建一个完整的智能问数系统；在 Dify Chatflow 中配置 MCP 工具节点；编写高质量的 NL2SQL System Prompt（含 Few-Shot 和反例）；将飞书机器人接入 Dify Chatflow API；调试和优化端到端的查询准确率。

课件最终交付物原文要点：

> `wide_order_details` 宽表创建成功，数据量 149,000+ 行；宽表索引创建完毕；Dify Chatflow 7 个节点全部配置正确；MCP 工具节点成功连接 MySQL 并执行查询；安全校验节点拦截写操作；飞书机器人事件订阅成功；8 个标准测试用例全部通过；System Prompt 经过至少 3 轮迭代优化；枚举值完整注入 Prompt；审计日志正常工作。

课件必做作业原文：

> 扩展宽表增加 `holiday_name`；增加同比和环比处理能力；添加毛利率、客单价、日均销售额、周均销售额、复购标记等分析字段。

## 2. 迁移说明

| 课件实现 | 本项目实现 |
|---|---|
| Dify Chatflow | LangGraph 状态图 |
| Dify LLM 节点 | DeepSeek adapter + 版本化 Prompt node |
| Dify 代码安全节点 | 独立 SQL 解析与策略节点 |
| MCP MySQL 工具节点 | 可替换数据库查询 adapter，默认 MySQL 只读连接 |
| Dify 结果格式化节点 | 结果校验与数据解读节点 |
| Dify 飞书卡片代码节点 | 飞书适配层 |
| Dify 结束节点 | FastAPI JSON/SSE 响应 |

保留课件业务数据、宽表、Prompt 方法、飞书入口和测试问题，不保留 Dify 运行时。

## 3. 数据范围

- 数据库：`shop_db`。
- 业务场景：全品类 B2C 电商。
- 数据模型：8 张维度表、2 张事实表、`wide_orders` 和 `wide_order_details`。
- 课件数据：约 5 万订单、14.9 万订单明细。
- 主要能力：汇总、排行、筛选、趋势、占比、同比、环比、退款率和工作日对比。

数据字典和指标口径在 `DATA-310` 形成机器可读真源，Prompt 不重复硬编码整套 Schema。

## 4. 功能范围

### 必做

- Web 和飞书自然语言提问。
- 意图识别与非数据问题拒答/引导。
- Schema、枚举和指标检索。
- 结构化生成单条 MySQL 查询。
- SQL AST 安全校验和只读执行。
- 查询结果结构校验、自然语言解读和表格输出。
- 趋势类问题生成 ECharts 图表语义。
- 会话与多轮追问，如“那上周呢”“只看华东区”。
- 查询运行、Prompt 版本、SQL 审查结果、耗时和错误审计。
- 推荐追问和结果截断。

### 课件扩展

- `holiday_name`。
- 同比、环比。
- 毛利率、客单价、日均/周均销售额和复购标记。
- 飞书推荐问题按钮和趋势图表。

## 5. Agent 工作流

```text
接收问题
-> 身份/限流/输入校验
-> 意图与上下文解析
-> Schema/指标/枚举检索
-> SQL结构化生成
-> SQL AST安全校验
-> MySQL只读执行
-> 结果结构与口径校验
-> 数据解读与图表语义
-> 审计并向Web/飞书流式输出
```

## 6. SQL 安全硬约束

- 数据库账号只读，安全不依赖 Prompt。
- 仅允许单条 `SELECT`；是否支持 CTE 在 `DATA-310` 明确。
- 表、列、函数和 schema 白名单。
- 禁止写操作、DDL、权限语句、文件读写、系统 schema、延时/资源消耗函数和多语句。
- 自动限制最大返回行数、执行时间和结果大小。
- LLM 结构化输出先经 Schema 校验，再经 SQL AST 校验，最后才允许执行。
- 审计日志记录 SQL 指纹和策略结果；原 SQL 的保存策略在详细设计确认。

## 7. 课件标准测试集

| 编号 | 问题 | 验证点 |
|---|---|---|
| T1 | 上个月总销售额多少 | 相对时间 |
| T2 | 各渠道销售额排行 | 分组排序 |
| T3 | 手机品类卖得最好的 5 个品牌 | 品类筛选与 TopN |
| T4 | 华东区金卡用户买了多少钱 | 多条件与占比 |
| T5 | 今年每个月销售额趋势 | 月度趋势 |
| T6 | 哪个支付方式用的人最多 | 占比计算 |
| T7 | 退款率最高的品类是哪些 | 聚合计算 |
| T8 | 周末和工作日哪个卖得多 | 二分类对比 |

所有测试以数据库基准 SQL 的结果为准，不以语言表达相似度代替执行正确性。

## 8. 非功能要求

- 8 个课件问题全部通过；扩展评测集目标执行正确率不低于 95%。
- 危险 SQL 测试必须全部拦截。
- 首个流式状态及时返回；完整延迟指标在 `DATA-310` 基于环境确认。
- 查询失败、空结果、歧义、超时和模型失败有不同错误语义。
- Web 和飞书共享 Agent 业务能力，但使用独立协议适配器。

## 9. 验收

- 课件数据、宽表和索引可复现。
- 8 个标准问题有自然语言、生成 SQL、基准 SQL、执行结果和最终回答证据。
- SQL 写操作、注释绕过、多语句、系统表、文件函数和超时攻击被阻断。
- 多轮追问不会串用户或串会话。
- 飞书和 Web 对同一问题使用同一 Agent 语义。
