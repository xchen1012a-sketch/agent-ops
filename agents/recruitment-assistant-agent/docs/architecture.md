# 智能招聘 Agent 架构

## 模块边界

```text
api/            任务、材料、运行、报告和反馈接口
application/    招聘分析用例与人工确认流程
workflows/      LangGraph 图、状态和恢复点
nodes/          解析、匹配、公平性、报告节点
prompts/        解析/匹配/面试 Prompt 版本
adapters/       DeepSeek、文档解析和对象存储适配
repositories/   MySQL 持久化
schemas/        材料、简历、JD、匹配和报告 Schema
```

目录名为详细实现阶段的目标结构，不代表当前已创建代码目录。

## 状态与幂等

- 一个分析任务拥有一个 `thread_id`，每次分析或重新分析拥有独立 `run_id`。
- 文件上传以内容摘要和租户/用户边界去重，不用原文件名作为唯一标识。
- 节点重试不得重复创建报告版本或覆盖人工修正结果。

## 人工复核

结构化简历、结构化 JD 和最终报告均保留版本。人工修正后产生新版本，不静默覆盖模型原始输出；报告必须记录使用的数据版本。
