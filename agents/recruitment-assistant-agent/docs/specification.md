# 智能招聘 Agent 规格（真源）

## 1. 课件原文依据

来源：`docs/homework/实训报告大纲.html`

课件对第二模块综合案例的原文要求：

> 综合案例（选一个：智能招聘助手 / 自定义场景）。

报告还要求该模块提供：

> 工作流总览（节点图）；各节点实现（附配置截图）；遇到的问题及解决方案；项目成果展示（工作流截图 + DSL 导出）。

课件未给出智能招聘助手更细的业务功能，因此本规格根据用户已确认的业务场景，将原 Dify 工作流能力迁移为可测试的 LangGraph Agent；新增内容必须与招聘辅助定位一致，不扩展为招聘管理系统。

## 3. 产品定位

帮助招聘人员对简历和岗位说明进行结构化整理、证据化匹配、差距分析和面试准备。系统只提供决策辅助，不自动作出录用、淘汰、薪资或歧视性结论。

## 4. 功能范围

### 必做

- 上传或粘贴简历文本，并结构化提取教育、经历、技能、项目和证书。
- 输入岗位说明，结构化提取职责、必备条件和加分条件。
- 依据岗位要求生成逐项匹配结果，并引用简历中的证据片段。
- 明确区分“匹配”“部分匹配”“未找到证据”，不得把缺失信息推断为事实。
- 输出能力差距和需要人工核实的问题。
- 基于岗位和候选人材料生成结构化面试问题。
- 生成可导出的招聘分析报告。
- 保存任务、材料元数据、结构化结果、运行记录和人工反馈。

### 不做

- 不自动决定录用或淘汰。
- 不基于性别、年龄、民族、婚育、照片等敏感属性评分。
- 不从外部网站自动抓取候选人隐私信息。
- 不建设完整 ATS、职位发布、Offer 或薪酬审批系统。

## 5. Agent 工作流

```text
接收任务与材料
-> 文件/文本安全校验
-> 任务类型路由
-> 简历结构化解析
-> JD结构化解析
-> 证据化匹配
-> 公平性与事实校验
-> 差距/面试问题/报告生成
-> 持久化与流式输出
```

所有解析和匹配结果必须通过 Pydantic Schema。评分维度来自岗位要求，不允许模型临时创造隐藏维度。

## 6. 数据边界

数据库：`recruitment_agent_db`。拟包含用户/角色、招聘分析任务、材料元数据、结构化简历、结构化岗位、匹配项、面试问题、报告、Prompt 版本、Agent 运行、节点运行和反馈等实体。

原始文件的保存位置、加密方式和保留期限在 `RECRUIT-210` 确认。

## 7. 非功能要求

- 简历和联系方式按敏感个人信息处理，不写入普通日志。
- 文件类型、大小、内容和解析超时由服务端校验。
- 结构化结果可人工修正；后续分析使用已确认版本。
- 每个匹配结论能追溯到岗位要求和简历证据。
- Agent 运行支持取消、有限重试和失败恢复。

## 8. 验收

- 相同材料重复执行可获得结构稳定、可解释的结果。
- 无证据项不会被模型填充为候选人能力。
- 敏感属性不进入匹配分数或推荐理由。
- 文件解析失败、模型超时和结构化校验失败均有明确错误。
- 报告包含匹配证据、差距、核实项和面试问题。

## 9. DESIGN-002 对齐结果

| 决策 | 真源 |
|---|---|
| 支持格式 PDF + 纯文本；单文件 ≤ 10MB、PDF 页数 ≤ 20、文本 ≤ 50KB；超限返回 413 | `agent-suite-ops/docs/adr/0009-recruitment-fairness.md` |
| 原始文件解析成功后立即删除，仅保留结构化结果与 hash 指纹；杀毒扫描在解析前执行 | ADR-0009 |
| 评分维度与权重：技能匹配 40% / 经验年限 25% / 学历背景 15% / 软技能 20%；权重在版本化规则真源 | ADR-0009 |
| 普通用户不可见数值分数，仅见三档定性结果（匹配 / 部分匹配 / 未找到证据）+ 证据；admin 可见完整评分与覆盖入口 | ADR-0009 |
| 敏感属性在解析节点直接剔除：年龄、性别、婚姻、户籍、民族、健康、政治面貌、照片、身份证号、籍贯、宗教信仰 | ADR-0009 |
| 所有匹配结果默认进入人工复核队列；admin 签字后才能生成最终报告 | ADR-0009 |
| 验收样本：AI 生成 20 份合成脱敏样本（含 5 份公平性对抗样本），用户审阅后入库 | ADR-0009 |

## 10. RECRUIT-210 仍需细化的项

- 数据实体 ER 图（任务、材料元数据、结构化简历、结构化 JD、匹配项、面试问题、报告、Prompt 版本、运行、节点、反馈、人工覆盖版本）。
- API Schema（请求 / 响应 / SSE 事件 / 错误码）。
- 节点 I/O 与失败语义（文件安全校验、任务路由、简历解析、JD 解析、证据匹配、公平性校验、差距、面试问题、报告）。
- 公平性测试集与对抗样本的具体定义。
