# 法律咨询 Agent 规格（真源）

## 1. 课件原文依据

来源：`AI编程_智能问数实训(课件)/03_AI法律咨询系统实战/03_AI法律咨询系统实战_Typora版.md`

课件目标原文：

> 使用 AI 提示词从头生成完整的前端页面（非玩具代码）；理解 SPA 的路由、状态管理和组件化思想；搭建 Node.js + Express 后端服务；使用 SQLite 实现数据持久化；在后端集成 DeepSeek API，实现流式 AI 法律问答；理解前后端分离架构的完整开发流程。

课件课后作业原文要点：

> 对话上下文记忆；完整的会话管理；对话历史搜索；密码修改；响应式布局优化；导出咨询报告。

## 2. 迁移说明

| 课件实现 | 本项目实现 |
|---|---|
| Node.js + Express | FastAPI |
| SQLite | MySQL 8 |
| DeepSeek 直连问答 | LangGraph 编排 + DeepSeek 官方 `deepseek-chat` |
| 单体前后端示例 | 独立 Agent API + 统一 Vue 3 前端 |
| Prompt 直接生成回复 | 分类、检索、生成、引用校验和安全提示节点 |

业务目标和课后功能保留，运行架构按用户确认方案迁移。

## 3. 用户与场景

- 普通用户：发起法律咨询、管理会话、搜索历史、导出报告。
- 管理员：管理用户、法律分类、知识材料、Prompt 版本和运行审计。
- 系统边界：提供一般性法律信息和材料整理，不替代律师，不保证形成正式法律意见。

## 4. 功能范围

### 必做

- 注册、登录、JWT 身份认证、密码安全存储与密码修改。
- 法律分类选择和分类绑定会话。
- 多会话创建、切换、删除和最近更新时间。
- 同一会话上下文记忆，默认限制最近消息窗口并支持摘要。
- DeepSeek 流式法律问答。
- 咨询记录持久化、关键词搜索和时间倒序。
- 单条与批量咨询报告导出，至少支持 Markdown 和 PDF。
- 管理员用户、分类、知识材料和 Prompt 版本管理。

### 高标准增强

- 基于法律知识材料的检索增强生成。
- 回答附可核验来源；来源不足时明确说明不确定性。
- 高风险问题提示线下专业咨询或紧急渠道。
- Prompt 注入防护、上传内容隔离和敏感信息最小化。
- 运行反馈与回答质量评估。

## 5. Agent 工作流

```text
接收问题
-> 输入安全与隐私检查
-> 法律领域/意图分类
-> 会话上下文构建
-> 法律知识检索
-> 回答生成
-> 引用与声明校验
-> 持久化与流式输出
```

LLM 输出必须经过 Pydantic Schema 校验。检索不到可靠依据时不得编造法条、案号或结论。

## 6. 数据边界

数据库：`legal_agent_db`。拟包含用户、角色、法律分类、会话、消息、咨询记录、知识材料元数据、Prompt 版本、Agent 运行、节点运行和反馈等实体。

表结构在 `LEGAL-110` 详细设计确认，不在本阶段固定字段。

## 7. 非功能要求

- API、数据库、DeepSeek 配置不硬编码。
- 密码使用安全哈希；Token 和密钥不得进入日志。
- 对话、上传材料和导出文件按隐私数据处理。
- Agent 运行支持超时、有限重试、取消和可追踪错误。
- 核心工作流可在不访问真实 DeepSeek/MySQL 的条件下单元测试。

## 8. 验收

- 完成课件六项课后功能。
- 多轮会话能正确引用上下文且不同会话隔离。
- 历史搜索、密码修改和报告导出具有 API 与端到端证据。
- 无来源时不伪造法律依据。
- 普通用户不能访问管理员资源或其他用户会话。

## 9. 待详细设计确认

- PDF 报告模板、保存周期和隐私清理策略。
