# agent-suite-ops

企业级多智能体应用平台的运维协调仓库。

## 职责

- 维护跨仓部署拓扑、Docker Compose、反向代理和环境变量模板。
- 维护跨仓架构决策、API 公共约定、可观测字段和运维手册。
- 维护并执行各仓 `.ai-spec/.ai-rules/development-standards.md` 规定的禁止硬编码、框架规范和质量门禁。
- 验证五个仓库的版本兼容性和健康检查。

## 不负责

- 不承载法律、招聘或智能问数业务代码。
- 不承载统一前端代码。
- 不保存总体计划、模块实施计划或真实密钥。
- 不把一个 Agent 的数据库权限授予另一个 Agent。

当前阶段仅建立文档，不包含可执行部署配置。
