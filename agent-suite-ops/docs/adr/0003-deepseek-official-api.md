# ADR-0003：使用 DeepSeek 官方 deepseek-chat

- 状态：已确认
- 日期：2026-07-04

## 决策

三个 Agent 使用 DeepSeek 官方 API 的 `deepseek-chat`。模型调用通过各服务内部 adapter 和配置对象封装。

## 约束

- API Key 仅由服务端环境变量注入。
- 超时、最大重试、温度、最大输出和模型名均配置化。
- 需要工具调用或结构化输出的节点不得切换到不支持相应能力的模型。
- 日志不得记录 API Key、完整 Prompt 或完整敏感输入。

## 回滚

若官方 API 不可用，可通过模型 adapter 切换兼容实现，但必须重新执行工具调用、结构化输出和轨迹评估。
