# ADR-0009：招聘材料处理与公平性规则

- 状态：已确认
- 日期：2026-07-04
- 阶段：DESIGN-002

## 背景

智能招聘 Agent 涉及简历、岗位说明等敏感个人信息，必须满足隐私保护、可解释、可追溯、公平性四项要求。课件未给出招聘助手的具体业务规则，本 ADR 在用户已确认场景下固化关键决策。

## 决策

### 文件处理

- 支持格式：PDF + 纯文本（首期不支持 Word、图片 OCR）。
- 大小限制：单文件 ≤ 10MB、PDF 页数 ≤ 20、文本 ≤ 50KB；超限返回 413。
- 文件存储：解析成功后立即删除原始文件，仅保留结构化结果与原始内容 hash 指纹（用于去重与审计）。
- 杀毒扫描：上传阶段调用 ClamAV 或等价 adapter；不通过则返回 422。

### 评分维度与权重

| 维度 | 权重 | 数据来源 |
|---|---|---|
| 技能匹配 | 40% | JD 必备技能 ∩ 简历技能 |
| 经验年限 | 25% | 简历工作经历与项目时长 |
| 学历背景 | 15% | JD 学历要求 vs 简历学历 |
| 软技能 | 20% | 项目角色、证书、推荐信（如有） |

权重值集中在版本化规则真源（数据库表或 YAML 文件），不在代码或 Prompt 中硬编码。

### 敏感属性屏蔽

- 屏蔽清单：年龄、性别、婚姻状况、户籍、民族、健康、政治面貌、照片、身份证号、籍贯、宗教信仰。
- 屏蔽时机：在简历结构化解析节点直接剔除上述字段，**不进入匹配、不进入 Prompt、不进入日志**。
- 公平性测试：每次发布前跑对抗样本集（敏感属性替换不应改变评分 ±5%）；超阈值则阻断发布。

### 人工复核

- 所有匹配结果默认进入人工复核队列；`admin` 必须签字后才能生成最终报告与导出。
- 复核可以覆盖：评分维度结果、差距分析、面试问题。
- 覆盖记录版本化保存，原结果不丢弃。

### 验收样本

- AI 生成 20 份合成脱敏样本（含 5 份对抗样本测试公平性），用户审阅后入库。
- 样本不包含任何真实候选人信息。

## 后果

- 招聘 Agent 不能流式自动出最终报告，必须等待人工签字。
- 简历/JD 解析失败的边缘案例（扫描版 PDF、损坏文件、空文件）必须有清晰错误码与重试路径。
- 评分规则调整需要走版本化流程，不允许热更新。
- 文件上传流量受限于大小与速率限制。

## 关键实现约束

- 评分权重、敏感属性清单、文件限制通过类型化 Settings 注入。
- 简历结构化 Schema 与 JD 结构化 Schema 独立版本管理。
- 公平性测试集与对抗样本集以 fixture 形式纳入 CI。

## 回滚

若评分规则在样本集上无法达到可解释性要求，可调整权重或降级为"匹配 / 部分匹配 / 未找到证据"三档定性输出，不输出数值分数。
