# ADR-0006：采用单仓模块化架构

- 状态：已确认
- 日期：2026-07-04
- 取代：ADR-0001

## 背景

用户确认需要将整套工程文件和计划文件统一推送到一个 GitHub 仓库，并排除本地课件资料。原五个项目仓的提交数均为 0，不存在业务历史迁移问题。

## 决策

- 项目根目录作为唯一 Git 仓库。
- 前端、三个 Agent、运维和计划保持独立目录与职责边界。
- 模块之间仍通过公开 API 契约协作，不引入共享业务数据库或隐式运行时耦合。
- 课件目录不进入 Git。

## 后果

- 工程与计划可以在一个提交中协同版本化。
- 模块可独立构建、测试和部署，但不再拥有独立 Git 历史。
- 修改多个模块时仍需在提交说明和验证中分模块记录影响。

## 回滚

如未来需要恢复多仓，以模块目录为边界拆分 Git 历史，并在拆分前冻结当前版本和 API 契约。
