## 🗺️ 推荐学习路径

### 路径一：初学者（按顺序学习）

```
01 开始 → 02 LLM → 11 结束 → 03 知识检索 → 04 条件分支 → 06 HTTP 请求
```

掌握以上 6 个节点后，即可构建 **80% 的常见工作流**。

### 路径二：进阶者（按场景学习）

| 场景 | 需要掌握的节点 |
|------|------|
| **智能客服/问答** | 开始 + 知识检索 + LLM + 答案 |
| **数据分析流程** | 开始 + 代码执行 + 模板转换 + 结束 |
| **多意图处理** | 开始 + 条件分支 + LLM + 变量聚合 + 结束 |
| **批量处理** | 开始 + 迭代 + LLM + 模板转换 + 结束 |
| **外部数据集成** | 开始 + HTTP 请求 + LLM + 结束 |
| **信息提取** | 开始 + 参数提取 + 代码执行 + 结束 |

### 路径三：完整工作流构建（综合实战）

```
将 12 个案例串联起来，构建一个完整的「智能招聘助手 Agent」：

用户上传简历 → 参数提取(10) → 条件分支(04)判断岗位类型
→ HTTP请求(06)获取行业薪酬数据 → 知识检索(03)查找公司资料
→ 代码执行(05)计算匹配分数 → 模板转换(07)生成报告
→ 变量聚合(08)合并多路 → LLM(02)综合评估 → 结束(11)输出报告
```
