📤 参数提取节点 — 简历信息提取

核心作用：参数提取节点利用 LLM 从非结构化文本中提取结构化数据。你定义「要提取什么字段」，它自动从用户输入的文本中抽取并填充。非常适合表单自动填写、文档信息提取等场景。

🎯 学习目标

学完本案例后，你将能够：

  • 配置参数提取节点，定义提取字段及类型
  • 理解参数提取与 LLM + 代码提取的区别
  • 将提取结果传给下游节点进行业务处理
  • 处理提取失败或信息缺失的情况

📚 案例描述

构建一个「简历信息自动提取器」，用户粘贴一段简历文本，系统自动提取姓名、电话、邮箱、学历、工作年限等结构化信息，然后由 LLM 生成岗位匹配度评估。

🔧 手把手实操

步骤 1：创建工作流

  1. 创建应用 → 「工作流」
  2. 命名为：简历信息提取器

步骤 2：配置开始节点

步骤 3：配置参数提取节点（核心）

  1. 拖入「参数提取」节点
  2. 连接：开始 → 参数提取
  3. 模型选择：deepseek-v4-flash（提取任务用快模型即可）

定义提取字段

在右侧配置面板中点击「添加参数」，定义以下字段：

提取指令（Instruction）

在「指令」输入框中，给 LLM 提供提取指导：

xxxxxxxxxx
请从以下简历文本中提取关键信息。
- 如果某项信息在简历中未提及，留空即可
- 学历请从选项中选择最匹配的一项
- 技能请拆分为列表，如 "Python, SQL, Hadoop"
- 工作年限请提取数字部分，如"3年" → 3

💡 参数描述的重要性：描述越清晰，LLM 提取越准确。描述是给 LLM 看的「字段定义说明」。

步骤 4：用代码节点验证提取结果

  1. 拖入「代码执行」节点（Python）
  2. 连接：参数提取 → 代码执行
  3. 输入变量：提取出的所有字段
xxxxxxxxxx
def main(name: str, phone: str, email: str, education: str,
         years_of_work, skills: list, last_company: str, expected_salary: str) -> dict:
    """验证提取结果的完整性"""
    
    issues = []
    
    # 必填字段检查
    if not name or len(name.strip()) < 2:
        issues.append("⚠️ 姓名未提取到或异常")
    if not education:
        issues.append("⚠️ 学历未识别")
    if not skills or len(skills) == 0:
        issues.append("⚠️ 技能列表为空")
    
    # 数据质量检查
    if phone and len(phone.replace('-', '').replace(' ', '')) < 11:
        issues.append("⚠️ 电话号码格式可能异常")
    if email and '@' not in email:
        issues.append("⚠️ 邮箱格式可能异常")
    
    # 处理 years_of_work 可能为 None
    work_years = years_of_work if years_of_work else 0
    
    return {
        "is_valid": len(issues) == 0,
        "issues": issues,
        "profile": {
            "name": name,
            "phone": phone or "未提供",
            "email": email or "未提供",
            "education": education,
            "work_years": work_years,
            "skills": skills or [],
            "last_company": last_company or "未提供",
            "expected_salary": expected_salary or "未提及"
        }
    }

步骤 5：配置 LLM 节点生成匹配评估

  1. 拖入 LLM 节点，连接：代码执行 → LLM
  2. 模型：deepseek-v4-pro（评估任务用强模型）

User Prompt：

​x
应聘岗位：{{#start.position#}}
​
候选人信息：
- 姓名：{{#code.profile.name#}}
- 学历：{{#code.profile.education#}}
- 工作年限：{{#code.profile.work_years#}} 年
- 技能：{{#code.profile.skills#}}
- 最近公司：{{#code.profile.last_company#}}
​
请评估该候选人与岗位的匹配度：
1. 技能匹配度（高/中/低）
2. 经验匹配度（高/中/低）
3. 综合评分（1-10 分）
4. 面试建议（50 字以内）
​
如果信息不完整（{{#code.is_valid#}}），请指出缺失的关键信息。

步骤 6：结束节点

输出变量：{{#llm.text#}}

📤 参数提取 vs 其他方案

💡 建议：结构化信息提取 → 参数提取节点；复杂自定义提取 → LLM + 代码节点。

💡 避坑指南

🏆 独立练习

  1. 新增提取字段：certifications（证书列表，如 PMP、AWS 认证）、languages（语言能力，如 英语 CET-6）
  2. 在代码验证节点中增加证书/语言能力的检查逻辑
  3. 修改 LLM Prompt，让评估报告中体现证书和语言能力的加分项

📌 一句话总结：参数提取节点 = 工作流的「信息提取器」，利用 LLM 从非结构化文本中提取结构化字段。定义好字段名 + 类型 + 描述，系统自动完成抽取。简历解析、发票识别、合同提取等场景的最优解法。
