## 🤔 情景导入：业务人员的困境

> *"张经理，上个月华东区销售额前 10 的商品是哪几个？"*

### 传统流程 ❌

1. 业务人员找数据分析师
2. 分析师理解需求（沟通损耗）
3. 手工编写 SQL
4. 等待查询执行
5. 导出 Excel / Markdown 报表
6. **耗时：2 小时 ~ 2 天**

### 智能问数 ✅

1. 业务人员在飞书直接提问
2. AI 理解自然语言
3. 自动生成 SQL 并执行
4. 即时返回结果 + 可视化图表
5. **耗时：10 秒 ~ 30 秒**

---

## 🎯 什么是「智能问数」

> **智能问数（Intelligent Data Querying）** 是指利用大语言模型（LLM）将用户的**自然语言问题**自动转化为**结构化查询语言（SQL）**，执行查询后将结果以**自然语言 + 可视化图表**的形式返回给用户的技术体系。

### 核心能力三要素

```mermaid
graph LR
    A["🗣️ 自然语言理解<br/>NLU"] --> D["🎯 智能问数<br/>NL2SQL"]
    B["🧠 SQL 自动生成<br/>Text-to-SQL"] --> D
    C["📊 结果解释与可视化<br/>NLG + Chart"] --> D
```

### 本质：降低数据查询门槛

| 角色 | 传统方式 | 智能问数方式 |
|------|----------|--------------|
| CEO/VP | 等周报 / 月报 | 飞书随口问 |
| 运营经理 | 提需求 → 等排期 | 自助查询 |
| 数据分析师 | 写 SQL → 出报表 | AI 辅助，效率 10x |
| 一线业务 | 无法接触数据 | 人人都是分析师 |

## 🔧 技术演进：从 SQL 到 ChatBI

```mermaid
graph TD
    A["2010 - 2015<br/>规则引擎时代<br/>模板匹配 / 语法树解析<br/>准确率 40-60%"]
    B["2016 - 2020<br/>深度学习时代<br/>Seq2Seq / BERT 微调<br/>准确率 60-75%"]
    C["2021 - 2023<br/>预训练大模型时代<br/>GPT-3 / Codex / T5<br/>准确率 75-85%"]

    A --> B --> C --> D
```

### 关键转折点

- **2022 年**：Codex 发布，首次证明 LLM 可以生成高质量 SQL
- **2023 年**：GPT-4 在 Spider 基准测试上达到 85.3% 准确率
- **2024 年**：MCP 协议发布，标准化 AI-数据库交互；Dify 等低代码平台成熟
- **2025-2026 年**：工程优化（宽表 + RAG + Few-Shot）将准确率推至 95%+
