# 法律咨询 Agent 详细计划

## 1. 模块身份

- 仓库：`agents/legal-consulting-agent`
- 真源规格：`agents/legal-consulting-agent/docs/specification.md`
- 技术栈：FastAPI、LangGraph、Pydantic v2、SQLAlchemy 2、Alembic、MySQL 8、DeepSeek `deepseek-chat`

## 2. 目标与成功标准

按课件完成法律咨询、用户认证、会话、历史搜索、密码修改和报告导出，并通过 LangGraph 增加可验证的分类、检索、生成、引用校验和风险提示。

成功标准：六项课后功能完整；会话隔离和权限正确；回答不伪造来源；流式、取消、重试和导出可验证；质量门禁全部通过。

## 3. 范围

- 用户、角色、登录、密码修改和管理员权限。
- 法律分类、会话、消息、咨询记录、历史搜索。
- 法律知识材料、检索、回答、来源和免责声明。
- Prompt/工作流版本、运行/节点审计、反馈。
- Markdown/PDF 单条和批量报告导出。

## 4. 不做事项

- 不替代律师或输出保证性法律结论。
- 不抓取未经授权的法律内容。
- 不把用户材料、完整对话、Prompt 或密钥写入普通日志。
- 不实现招聘、智能问数或跨 Agent 调用。
- 不硬编码分类、模型、知识库路径、权限或报告模板。

## 5. 前置决策（LEGAL-110）

- 法律知识来源、许可、更新和失效机制。
- 统一认证是否覆盖三模块；角色和资源权限矩阵。
- 会话上下文窗口、摘要和删除策略。
- 上传类型/大小、隐私保留和导出文件清理策略。
- 引用格式、高风险问题升级规则和验收样本。

未确认时不得进入工程初始化。

## 6. 子阶段

### LEGAL-110 详细设计

- 产物：用例、权限矩阵、实体关系、API Schema、节点 I/O/失败语义、错误码、样本集和课件追踪矩阵。
- 验证：规格无待确认项；用户确认；不涉及代码。

### LEGAL-120 工程基础

- 工作：按 FastAPI/LangGraph 官方结构建立应用、类型化配置、健康检查、日志、数据库会话、Alembic 和质量工具。
- 产物：最小可运行服务、`.env.example`、测试基座、Dockerfile。
- 验证：启动、OpenAPI、live/ready、Ruff、MyPy、Pytest、迁移检查、镜像构建通过。
- 回滚：移除本阶段新增应用骨架，不影响规格和计划。

### LEGAL-130 身份与数据层

- 工作：用户/角色、分类、会话、消息、咨询、Prompt版本、运行/节点、反馈和导出任务表；认证和资源授权。
- 验证：迁移升级/回滚、唯一性、级联、并发事务、越权和密码安全测试通过。
- 停止：统一认证边界变化或需要跨库访问。

### LEGAL-140 Agent 工作流

- 节点：输入安全、领域分类、上下文、知识检索、回答生成、引用校验、风险提示、持久化。
- 约束：每节点显式 Schema；LLM 输出校验；外部调用 adapter 化；Prompt 版本化。
- 验证：正常、无来源、Prompt 注入、模型超时、校验失败、重试、取消、幂等和恢复测试。

### LEGAL-150 领域 API 与课件功能

- 工作：注册登录、密码修改、会话 CRUD、流式问答、历史搜索、管理接口、报告导出。
- 验证：OpenAPI 契约、错误响应、SSE 顺序/断线、搜索、导出和课件六项功能端到端通过。

### LEGAL-160 质量与验收

- 工作：轨迹评测、安全、隐私、性能、故障恢复、可观测和课件演示证据。
- 验证：Ruff、MyPy、Pytest、契约、迁移、安全扫描、镜像扫描和验收样本全通过。
- 交付：测试报告、架构图、API文档、迁移说明、课件原文映射和演示步骤。

## 7. 配置与禁止硬编码

DeepSeek、MySQL、JWT、对象存储、超时和限流由类型化 Settings 注入；分类/权限/Prompt/风险规则使用数据库或版本化规则真源；报告模板独立版本管理。

## 8. LangGraph 与 Deep Agents 演进边界

- 默认使用自定义 LangGraph，保持节点、状态、路由和人工复核规则显式可测。
- 仅当多文档长程任务、动态任务分解、受控文件工作区或子 Agent 协作成为已验证需求时，评估 Deep Agents。
- 通过统一 graph factory 切换实现；API、领域模型、持久化契约和审计模型不得随运行时切换而变化。
- 引入前必须完成法律数据隔离、工具权限、沙箱、成本、时延和回归评测，并形成独立 ADR；不得并行维护两套业务工作流。

## 9. 风险与停止条件

- 法律知识无合法来源或无法更新。
- 身份/权限和数据删除策略未确认。
- 回答需要未经验证的外部事实。
- 需求扩大为正式法律意见或律师业务系统。

出现任一项时停止当前阶段并与用户对齐。
