# 统一 Web 前端详细计划

## 1. 模块身份

- 仓库：`agent-suite-web`
- 真源规格：`agent-suite-web/docs/specification.md`
- 技术栈：Vite、Vue 3、TypeScript、Element Plus
- 职责：三个业务菜单、交互、展示、客户端状态和公开 API/SSE 集成

## 2. 目标与成功标准

构建现代化统一 Web 入口，三个模块界面和状态相互隔离。任一 Agent 下线只影响对应菜单；前端不承载 Agent、Prompt、SQL、权限判定或领域计算。

成功标准：四个目标断点可用；三模块主流程端到端通过；SSE 可停止、重连、去重；API 类型来自契约；构建、类型、单测和 E2E 门禁通过。

## 3. 范围

- 应用壳、路由、菜单、身份状态、错误边界和主题系统。
- 法律咨询、智能招聘、智能问数三个功能模块。
- 每模块独立 view/component/store/api-client。
- OpenAPI 类型生成或契约校验、SSE 客户端、统一错误映射。
- 响应式、无障碍、加载/空/错误/降级状态。

## 4. 不做事项

- 不实现后端业务、模型调用、Prompt、SQL 或数据库访问。
- 不硬编码 API 地址、超时、菜单权限、错误字段或图表业务口径。
- 不建立跨模块万能 store/service。
- 不把服务端运行状态伪造为前端本地完成状态。

## 5. 前置决策（WEB-410）

- 统一认证与 Token 生命周期。
- 三模块路由、角色菜单和授权失败体验。
- OpenAPI TypeScript 工具及生成目录。
- SSE 断线恢复、停止和重复事件策略。
- 视觉 Token、暗色模式范围和四断点布局。
- 文件上传限制和 Markdown 安全渲染方案。

以上未确认时不得进入工程初始化。

## 6. 子阶段

### WEB-410 详细设计与契约

- 产物：路由图、页面清单、组件边界、状态模型、API 映射、错误矩阵、交互原型。
- 验证：三 Agent OpenAPI 草案逐项有调用方；无未定义字段；用户确认。
- 回滚：仅回滚文档到最后确认版本。

### WEB-420 工程基础

- 工作：按官方 Vite/Vue 3 模板建立 TypeScript 工程；配置 Element Plus、路由、状态、lint、格式、类型、单测和环境配置。
- 产物：最小 App Shell、健康/配置检查、质量命令和 `.env.example`。
- 验证：安装、lint、vue-tsc、单测和 production build 通过。
- 停止：依赖版本或许可证未确认；需要修改依赖源码。

### WEB-430 公共交互基础设施

- 工作：HTTP/SSE client、错误映射、身份状态、请求取消、事件去重、日志关联 ID。
- 验证：mock 契约测试覆盖成功、超时、断线、重复事件、取消和 401/403/5xx。
- 回滚：按模块关闭新 client，保留 App Shell。

### WEB-440 法律咨询界面

- 工作：咨询会话、分类、历史搜索、密码修改、报告导出和管理员入口。
- 验证：与法律 Agent 契约测试和关键 E2E 通过；不同用户数据隔离由后端证据验证。

### WEB-450 智能招聘界面

- 工作：任务、简历/JD材料、结构化校对、匹配报告、面试问题、人工反馈。
- 验证：上传失败、解析失败、人工修正、报告生成和敏感信息展示规则通过。

### WEB-460 智能问数界面

- 工作：对话、表格、ECharts 图表、查询历史、运行详情和推荐追问。
- 验证：表格截断、图表无数据、查询失败、多轮追问、取消和重试 E2E 通过。

### WEB-470 视觉与发布验收

- 工作：375/768/1024/1440 响应式、无障碍、性能预算、跨浏览器和视觉回归。
- 验证：ESLint、Prettier、vue-tsc、单测、构建、关键 E2E、视觉检查全部通过。

## 7. 配置与禁止硬编码

API 基址、超时、功能开关和环境标识由类型化配置提供；路由名、错误码和契约字段集中管理；前端不保存 DeepSeek、MySQL 或飞书密钥。

## 8. 风险与停止条件

- 三 Agent 契约未冻结或互相冲突。
- 统一认证方案未确认。
- 页面需要依赖未公开的后端字段。
- 为复用而引入跨模块业务耦合。

出现任一项时停止当前子阶段，更新计划并与用户对齐。
