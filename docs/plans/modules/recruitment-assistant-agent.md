# 智能招聘 Agent 详细计划

## 1. 模块身份

- 仓库：`agents/recruitment-assistant-agent`
- 真源规格：`agents/recruitment-assistant-agent/docs/specification.md`
- 技术栈：FastAPI、LangGraph、Pydantic v2、SQLAlchemy 2、Alembic、MySQL 8、DeepSeek `deepseek-chat`

## 2. 目标与成功标准

实现课件允许的智能招聘助手综合案例：结构化简历/JD、证据化匹配、差距分析、面试问题、人工复核和报告。系统只辅助决策，不自动录用或淘汰。

成功标准：结果可追溯到岗位要求和简历证据；敏感属性不参与评分；解析/匹配 Schema 稳定；人工修正可版本化；质量和公平性门禁通过。

## 3. 范围

- 招聘分析任务、材料上传/粘贴和安全解析。
- 简历与 JD 结构化、人工修正和版本管理。
- 匹配状态、差距、核实项、面试问题和报告。
- Agent 运行、Prompt 版本、反馈和审计。

## 4. 不做事项

- 不做 ATS、职位发布、Offer、薪酬或审批系统。
- 不自动决定录用/淘汰，不使用敏感属性评分。
- 不抓取候选人外部隐私，不保存无必要的原始材料。
- 不实现其他 Agent 业务或跨库访问。
- 不硬编码评分权重、岗位字典、文件限制或 Prompt。

## 5. 前置决策（RECRUIT-210）

- 支持的文件格式、大小、页数、语言和失败处理。
- 原始文件存储、加密、保留、删除和脱敏规则。
- 匹配维度、权重、分数展示和人工覆盖方式。
- 敏感属性清单、公平性测试和人工审核节点。
- 脱敏简历/JD验收数据集和预期结果。

## 6. 子阶段

### RECRUIT-210 详细设计

- 产物：用例、材料生命周期、实体关系、API Schema、节点 I/O、评分规则真源、公平性规则、错误码和样本集。
- 验证：课件综合案例边界明确；未决项清零；用户确认。

### RECRUIT-220 工程基础

- 工作：FastAPI/LangGraph 官方结构、配置、健康检查、日志、SQLAlchemy/Alembic、文件 adapter、测试和 Docker 基座。
- 验证：启动、OpenAPI、质量命令、迁移和镜像构建通过。
- 停止：文件存储/杀毒方案或依赖许可证未确认。

### RECRUIT-230 材料与结构化解析

- 工作：任务、材料元数据、简历/JD Schema、解析节点、人工修正和版本模型。
- 验证：正常/损坏/超限/空白/恶意文件；结构化校验失败；重复上传；隐私日志检查。

### RECRUIT-240 匹配与面试工作流

- 节点：任务路由、简历解析、JD解析、证据匹配、公平性校验、差距、核实项和面试问题。
- 验证：无证据不推断；敏感属性不影响结果；权重来自规则真源；重试和幂等通过。

### RECRUIT-250 API、报告与人工复核

- 工作：任务/材料/版本/运行/报告/反馈 API，SSE，停止重试，报告导出。
- 验证：OpenAPI、错误、并发版本、人工修正、报告追溯和权限测试通过。

### RECRUIT-260 质量与验收

- 工作：结构化准确性、轨迹、公平性、安全、隐私、性能、恢复和演示证据。
- 验证：Ruff、MyPy、Pytest、契约、迁移、安全/依赖/镜像扫描和脱敏样本集通过。
- 交付：工作流图、节点证据、API文档、测试报告、课件映射和演示步骤。

## 7. 回滚方式

- 详细设计阶段只回滚文档到最后确认版本。
- 数据迁移必须提供对应 Alembic downgrade，并先验证备份恢复。
- 工作流按版本切换回上一稳定图和 Prompt，不覆盖历史运行记录。
- 文件解析或报告能力异常时可单独关闭对应 adapter，保留任务查询和人工复核能力。

## 8. 配置与禁止硬编码

模型、数据库、文件限制、保留期、评分权重和敏感属性规则均使用类型化配置或版本化规则真源；Prompt 独立版本管理；前端和 API 不复制评分规则。

## 9. LangGraph 与 Deep Agents 演进边界

- 默认使用自定义 LangGraph，确保解析、证据匹配、公平性校验和人工复核路径可解释、可复现。
- 仅当跨大量材料的长程规划、受控文件工作区或独立子任务协作成为已验证需求时，评估 Deep Agents。
- 通过统一 graph factory 切换实现；API、领域模型、评分规则真源、审计和人工复核契约保持稳定。
- 引入前必须验证候选人数据隔离、文件工具权限、沙箱、公平性、成本、时延和回归集，并形成独立 ADR；不得由 Deep Agents 绕过人工复核。

## 10. 风险与停止条件

- 缺少合法脱敏样本或原始材料处理授权。
- 用户要求自动录用/淘汰或敏感属性评分。
- 匹配规则无法解释或没有岗位要求依据。
- 需求扩大为完整招聘管理系统。

出现任一项时停止当前阶段并与用户对齐。
