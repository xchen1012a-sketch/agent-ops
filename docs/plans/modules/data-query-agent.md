# 智能问数 Agent 详细计划

## 1. 模块身份

- 仓库：`agents/data-query-agent`
- 真源规格：`agents/data-query-agent/docs/specification.md`
- 技术栈：FastAPI、LangGraph、Pydantic v2、SQLAlchemy 2、Alembic、MySQL 8、DeepSeek `deepseek-chat`
- 课件链路：自然语言 → NL2SQL → MCP/MySQL → 数据解读 → Web/飞书

## 2. 目标与成功标准

保留课件 `shop_db`、星型模型、宽表、MCP查询、Prompt方法、飞书和8题测试，将 Dify Chatflow 迁移为独立 LangGraph Agent API。

成功标准：课件8题全部执行正确；扩展集目标不低于95%；危险SQL全部拦截；关键数字来自查询结果；Web和飞书语义一致；审计、取消、重试和故障隔离可验证。

## 3. 范围

- `shop_db` 数据字典、业务枚举、指标口径和宽表扩展。
- 意图/上下文、Schema检索、SQL结构化生成和AST策略。
- MCP MySQL查询适配、结果校验、解读和ECharts语义。
- 会话、多轮追问、查询历史、评测、审计和反馈。
- 飞书长连接、消息去重、流式卡片、推荐问题和图表。

## 4. 不做事项

- 不允许任何LLM输出直接执行SQL。
- 不使用高权限或写权限账号查询 `shop_db`。
- 不在Prompt散落完整Schema、指标口径、枚举或安全白名单。
- 不允许模型重算并改变数据库关键数字。
- 不实现法律、招聘或跨Agent调用。

## 5. 前置决策（DATA-310）

- 固定 MCP 为课件查询主链路；明确 MCP server、tool schema、超时和错误语义。
- 分离 `shop_db` 只读查询账号与 `data_query_agent_db` 运行态写账号。
- 表/视图/列/函数白名单、CTE/子查询/聚合允许范围和结果上限。
- 指标字典、枚举、时间语义、同比/环比和退款口径。
- SQL/结果审计保留策略及普通用户是否可见SQL。
- 飞书测试租户、权限、消息范围和图片/卡片限制。

## 6. 子阶段

### DATA-310 详细设计与基准

- 产物：数据字典、指标字典、权限矩阵、MCP契约、SQL策略、实体关系、API Schema、节点I/O、错误码、8题基准SQL和扩展评测集。
- 验证：基准SQL在固定数据快照可复现；未决项清零；用户确认。

### DATA-320 工程与双数据域基础

- 工作：FastAPI/LangGraph结构、配置、健康检查、日志、SQLAlchemy/Alembic、MCP/DeepSeek adapter接口、测试和Docker基座。
- 数据：`shop_db`只读连接；`data_query_agent_db`运行态连接。
- 验证：独立启动、OpenAPI、质量命令、运行态迁移、只读权限负向测试和镜像构建通过。

### DATA-330 Schema检索与SQL生成

- 工作：问题/上下文解析、Schema/指标/枚举检索、版本化Prompt、结构化SQL候选。
- 验证：字段/枚举/指标选择、相对时间、TopN、趋势、同比环比、无关问题和结构化校验测试。
- 停止：需要把整库Schema硬编码进Prompt或无法确定指标真源。

### DATA-340 SQL策略与MCP执行

- 工作：AST解析、白名单、单语句SELECT、资源限制、MCP调用、结果Schema和错误映射。
- 验证：写操作、DDL、权限语句、多语句、注释绕过、系统库、文件函数、延时函数、超时、大结果和越权字段全部测试。
- 回滚：禁用执行入口，保留离线生成/校验能力。

### DATA-350 解读、多轮与图表

- 工作：结果事实绑定、自然语言解读、表格截断、图表Schema、会话上下文、推荐追问、审计和反馈。
- 验证：关键数字一致、空结果、异常趋势、图表无数据、多轮改写、会话隔离、取消/重试/幂等通过。

### DATA-360 评测与质量验收

- 工作：课件8题、扩展评测、安全攻击、性能、故障恢复、可观测和Prompt至少3轮可追溯迭代。
- 验证：8题100%；扩展执行正确率目标≥95%；危险SQL拦截100%；Ruff/MyPy/Pytest/契约/迁移/扫描通过。

### FEISHU-500 飞书接入

- 工作：应用权限、长连接、事件解析、`message_id`去重、用户/会话映射、流式CardKit、推荐按钮、趋势图和错误提示。
- 验证：单聊、群聊@、重复消息、非文本、超时、断线、卡片大小、递增sequence和敏感日志检查通过。
- 回滚：关闭飞书adapter，Web智能问数继续可用。

## 7. 配置与禁止硬编码

MCP地址/tool名、DeepSeek、数据库、白名单、限制、指标、枚举、Prompt和飞书凭据分别使用类型化配置、版本化目录或Secret；所有关键配置启动时校验并快速失败。

## 8. LangGraph 与 Deep Agents 演进边界

- 默认且优先使用自定义 LangGraph，使 SQL 生成、AST 校验、权限检查、MCP 执行和事实绑定保持确定性边界。
- Deep Agents 不作为初始依赖；只有出现已验证的复杂分析规划需求，且自定义 LangGraph 的可维护性或评测结果不足时才进入评估。
- 即使采用 Deep Agents，也只能通过统一 graph factory 接入，且不得拥有绕过 SQL 策略层、MCP adapter、只读账号或结果校验的工具路径。
- 引入前必须形成独立 ADR，并通过全部 SQL 安全攻击集、权限负向测试、成本、时延和课件基准回归；不得并行维护两套业务工作流。

## 9. 风险与停止条件

- 如需取消课件要求的 MCP 查询链路，必须视为范围变更并取得用户确认。
- `shop_db`无法提供只读账号或稳定数据快照。
- 指标口径、数据字典或枚举存在冲突。
- 飞书权限/测试租户不可用却要求宣称端到端完成。
- 准确率提升需要扩大数据或模型范围。

出现任一项时停止当前阶段，记录证据并与用户对齐。
