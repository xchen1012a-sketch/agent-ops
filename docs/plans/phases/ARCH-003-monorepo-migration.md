## 目标

## 范围

- 保留前端、三个 Agent、运维模块和项目计划的目录边界。
- 移除子目录和 `.ai-spec` 的嵌套 Git 元数据。
- 在项目根目录建立 `main` 和 `develop` 分支。
- 绑定并推送到 `https://github.com/xchen1012a-sketch/agent-ops.git`。

- 不引入业务代码或依赖。
