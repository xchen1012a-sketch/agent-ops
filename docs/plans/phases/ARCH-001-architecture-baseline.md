# ARCH-001 多仓架构与文档基线

> **架构变更说明**：本阶段原计划"五仓独立 Git"已由 `agent-suite-ops/docs/adr/0006-monorepo-boundary.md` 调整为"单仓模块化"。下文保留原验收标准以供历史追溯，**当前事实以 ADR-0006 为准**：
> - 项目根目录是唯一 Git 仓库，分支 `main`，远端 `https://github.com/xchen1012a-sketch/agent-ops.git`。
> - 5 个模块目录保留独立职责与构建/测试/部署边界，但不再拥有独立 `.git`。
> - 课件目录通过 `.gitignore` 排除。

## 目标

在不编写业务代码的前提下，建立后续开发必须遵循的计划、模块边界、架构决策、模块规格和 API 草案。

## 范围（原计划，已部分由 ADR-0006 调整）

- 建立项目级计划体系（原"父目录非 Git"已调整为单仓 Git）。
- 在 `agents/` 下集中放置三个 Agent 模块目录，与前端、运维模块共同组成 5 个独立模块（不再独立 Git）。
- 为每个模块建立项目级规则入口、README 和架构/规格文档。
- 在运维模块记录跨模块架构、ADR、API 约定、可观测性和部署拓扑。
- 建立三个 Agent 的模块子阶段计划。

## 不做事项

- 不安装 Python、Node 或 Docker 依赖。
- 不创建可执行应用入口、业务代码、数据库迁移或 Compose 文件。
- 不调用 DeepSeek、飞书或 MySQL。
- 不执行 `git add`、`git commit`、`git push`。

## 验收标准（原计划）

- ~~父目录不存在 `.git`。~~（由 ADR-0006 推翻：父目录现为唯一 Git 仓库）
- ~~5 个约定子目录各自存在独立 `.git`，默认分支为 `main`。~~（由 ADR-0006 推翻：5 个模块为普通目录）
- 每个模块具有独立职责说明和禁止跨界事项。（仍生效）
- 总体架构文档描述请求链路、数据边界、部署边界和失败隔离。（仍生效）
- 三个 Agent 规格包含课件原文依据、迁移解释、功能范围和未决事项。（仍生效）
- API 草案包含请求、响应、错误、流式和运行状态约定。（仍生效）
- 文件扫描确认未创建 `.py`、`.vue`、`.ts`、`.js` 或可执行 Compose 配置。（仍生效）

- 2026-07-04：`package.json`、`pyproject.toml`、`requirements.txt`、Dockerfile 和可执行 Compose 文件数量为 0。
- 2026-07-04：ADR-0006 决策单仓模块化，原"5 个独立 Git 子仓"事实由 ADR-0006 替代。

结论：`ARCH-001` 验收通过（架构边界由 ADR-0006 调整，文档与计划基线完整）。

## 回滚方式

本阶段仅新增目录和文档。如需回滚，先列出新增路径并经用户确认后删除；不得删除课件、作业模板或现有 `.ai-spec`。

## 停止条件

- 模块命名或职责边界发生变化。
- 需要新增第四个业务服务或共享业务运行库。
- 文档要求与课件原文冲突且无法通过迁移说明消解。
